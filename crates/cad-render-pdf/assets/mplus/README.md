# Bundled M+ font

`mplus-1p-regular.ttf` is M+ 1p Regular from the `rayshan/mplus-fonts`
repository at commit `0d4459efc913a91f33c3f08b219a5a95d282c7b8`.

- Source: <https://github.com/rayshan/mplus-fonts>
- Font SHA-256: `aba60f31e2355eee243c60a024b0497bba3102fa6a6ab5bb73be00337417440a`
- License: SIL Open Font License 1.1; see `OFL.txt`.

The PDF renderer embeds only the glyph subset used by each document. The font
name in the PDF is prefixed to avoid colliding with an installed full font.
