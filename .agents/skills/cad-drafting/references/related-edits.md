# 寸法・ブロック・関連図面の更新

既存の `dimension` と `block_ref` を使って更新漏れを減らす。ブロックは部品の形と配置を共有する仕組みであり、壁開口・建具表・別図面の立面を自動更新する仕組みではない。現在の対応範囲は `crates/cad-model/src/lib.rs`、参照寸法は `crates/cad-model/src/dimensions.rs` に照合する。

## 寸法を対象に追従させる

- 新設・変更する寸法では、同じ座標スコープに安定した対象図形があれば `measurement` 内のアンカーに `kind: entity` を使う。既存の固定寸法を依頼と無関係に一括変換しない。
- 線の端点なら `start/end`、円の中心なら `center`、ポリラインの頂点なら `vertex` と `index` を使う。対象図形で利用できるfeatureを実装に照合する。例と構文は [正本編集の手引き](source-editing.md) の「寸法」を参照する。
- 参照は同一図面内、または同一ブロック定義内に限る。図面から配置済みブロック内部への参照や、`block_ref` の挿入点への参照は現在利用できない。未知のアンカー形式を追加しない。
- 実測表示は `value: null`。`p1/p2` は既存の形式と整合させるが、`measurement` があると測定はアンカーから決まる。座標だけを変更して参照先を放置しない。
- 短い壁芯線の分割やポリラインの頂点並べ替えで参照点が変わる場合、参照先を対応更新する。適切な参照対象がない設計基準点は固定アンカーのまま使い、対応関係を記録して移動時に更新する。参照にするためだけの可視図形は追加しない。

### 通り芯と寸法列

修正前に、芯番号・軸位置・芯図形ID・その芯で区切る寸法IDを対応付ける。番号は階と図面を含めて識別する。同じ番号の別階や、X7とX7′を取り違えない。

- 芯を移動：番号・丸・マスク・軸線の位置を更新し、該当する上下／左右の寸法列と測定アンカーを合わせる。
- 芯を追加：必要な寸法区間を分割する。既存寸法の更新ではIDを維持し、増えた区間だけ新IDにする。
- 芯を削除：対応する寸法区切りを見直し、不要なら隣接区間を結合する。壁や開口の位置を示す独立した寸法は、芯番号の削除だけを理由に消さない。
- 寸法列ごとに端点の順序・連続性・重複・区間合計と全体寸法の一致を確認する。全幅・全長の寸法は芯の整理によって変わらない。

参照寸法は位置の変更に追従するが、寸法列の分割・結合は自動ではない。芯図形の見た目の長さと測定の基準位置を区別し、短縮や端部延長で測定値が変わらない参照を選ぶ。

## ブロックで部品を扱う

枠・ガラスなど同じ配置基準で動く窓の姿図、テレビと台の組合せ、反復する製品部品にはブロックを検討する。新規部品の準備時や、一式で移動・再利用する依頼で使う。既存の独立図形を、軽微な修正のたびにブロックへ作り直す必要はない。

- 平面用と立面用は別の形として定義する。同じ部品の番号で対応付けても、平面図形を立面として流用しない。
- 部品基点と実寸mmを明示する。`block_ref` の正の一様 `scale`、`rotation_deg`、`mirror_x/mirror_y` を使う。製品の幅や高さの変更を非一様拡縮で済ませない。
- 定義の編集は全配置へ影響する。単独の窓の品種・寸法変更なら別定義を用意し、該当配置だけ参照を切り替える。共有定義内に配置ごとに異なる建具番号や窓下端高を固定しない。
- 一式で動く注記・寸法も対象に含めるか、配置に対応する独立図形として更新する。注記の回転と読みやすさは別途確認する。
- 壁輪郭・壁ハッチ・周辺の寸法を窓部品に取り込まない。壁は壁側で編集し、窓との位置対応を確認する。
- 既存図形をブロックへ組み替える場合は、参照寸法と案件の対応記録への影響を先に調べる。IDや参照の扱いは既存の複写・部品操作と [正本編集の手引き](source-editing.md) に従う。

## 建具番号で関連箇所を結び付ける

複数図面を横断する修正では、案件の既存台帳や作業メモへ対応を記録する。正本の未知フィールド、`comments/`、履歴領域へ意味情報を追加しない。新しい台帳の形式をCADの必須仕様として扱わない。

必要な対応は、建具番号と階、図面名、該当図形IDまたはブロック配置ID、壁開口と壁塗りのID、記号・引出線・寸法のID、建具表の行、立面・展開図のID、選定寸法と取付高さ。既存の対応記録があれば利用し、変更した箇所を更新する。文字検索や行番号だけで確定せず、座標・図種・現在のIDで対象を照合する。

たとえばW108の品種・位置変更では、次を同じ修正として扱う。

| 対象 | 確認・更新するもの |
| --- | --- |
| 平面図 | 部品、壁開口、壁ハッチ、番号、呼称、下端高、引出線、必要な寸法 |
| 独立立面・壁面展開 | 品種の姿図、壁内の左右位置、幅・高さ、FLからの下端・上端、寸法 |
| 建具表 | 有効な番号の所属行、仕様、姿図、選定資料との対応 |
| 案件の選定表・検査台帳 | 製品寸法、開口軸、図形ID、今回変わった選定情報 |

建具を廃止した場合は現在の一覧・立面の表示も整理し、表に不要な空行を残さない。過去の出力・選定履歴は現在の表と区別して保持する。

## 修正の確認

必要な関連箇所の更新を完了してから、通常のCADチェックと描画確認を行う。参照が有効なだけで、寸法区切りや図面間の整合が正しいとは限らない。

- 参照寸法：対象の移動・寸法変更後も意図した測定点と値になっているか。固定アンカーを残した箇所も追従させたか。
- ブロック：単独配置の変更が他の配置に波及していないか。回転・反転後の部品、文字、寸法に取り残しがないか。
- 関連図面：同じ番号で品種・寸法・位置・取付高さが整合するか。変更前の姿図や表記が残っていないか。
- SVGと実PDF：文字・寸法の重なり、表の行と姿図の対応、用紙内の収まりを確認する。

機能追加やAI編集用Undoの実装へ作業を広げない。Gitで復元する運用では対象の正本が追跡されているか確認し、管理対象外なら変更前の退避を残す。Git管理対象への変更自体は今回の作図と区別する。
