# 2D CAD 受入図面

`examples/cad-acceptance` は schema 0.3 の自前図面です。旧形式の移行用データではありません。

## 自動確認

- `apps/viewer/tests/e2e/output-acceptance.spec.ts`でSVG/PDFの画像をmacOS/Chromiumの確認済み基準画像と比較する。PDF画像化には`pdftoppm`（Poppler）が必要。別OSやフォント環境の基準画像は目視確認してから追加し、自動更新で差異を承認しない。
- checker が CAD と JWW v600 の両対象でエラーを返さない。
- 水平5000 mm、垂直4000 mm、平行1500 mm、角度60°、直径1200 mm、半径500 mmを共通評価処理で検証する。
- 右側の壁頂点を300 mm動かすと水平寸法は5300 mmとなり、垂直寸法は4000 mmを維持する。
- SVG/PDFに全寸法と反転ブロック、穴付きcrossハッチを描画する。
- JWW best-effortはJSONレポート付きで出力し、寸法の線・円弧・文字展開、線種・用紙の近似を確認する。グレーのハッチ線と破線の色はJWWの既定ペン色へ近似され、SVG/PDFと色が変わる。strictは近似をブロックし、既存出力を更新しない。
- JWW再読込みで線分、円弧、文字、ブロックを保持する。元の寸法参照関係はJWWへ保存されない。
