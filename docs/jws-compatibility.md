# JWS取り込みの検証範囲

2026-10-03。`cadc import-jws` は版351・420・600のJWSを新しい正本プロジェクトへ変換する。`copy-jws` とDesktopのJWS部品読込も同じ変換器を使い、検査済みのクリップボードを配置する。JWS再出力、JWK/JWC、現行Unicode形式の対応完了を意味しない。

## 根拠と読取り

ヘッダー構成は、読取りソフト作者の[公式掲示板での解析記録](https://www.jwcad.net/log/consult2/consult2-0610-12/thread17752.htm)を参照した。同記録は旧版の独自解析であり、後続版を保証していない。[公式JWWレコード仕様](https://www.jwcad.net/jwdatafmt.txt)と配布サンプルの全バイト読取りを合わせ、実データで確認できた版だけを有効にした。

JWSの先頭識別子・192個のピリオド、版番号、原点、16個の縮尺、72バイトの未解釈領域、範囲を検査する。原点・範囲は有限値、縮尺は有限正値を要求する。図形とCDataList定義部は一つのMFCクラス表を共有し、定義リスト数はWORD。クラスschemaは対象版と一致する必要がある。未知クラス・schema、PID、説明できない末尾は阻止し、レコード長を推測しない。未解釈のヘッダー領域は報告に保存し、意味を解釈したと主張しない。

## 実データ検証

[公式配布](https://www.jwcad.net/download.htm)のJw_cad 10.03.6インストーラを実行せずにデータだけ取り出した。研究用の取得・抽出物はignoredの `build/format-research/` に置き、サンプル原文はリポジトリへ再配布していない。

| 対象 | 結果 |
|---|---|
| JWS 351 | 311ファイルを末尾まで読取り |
| JWS 420 | 3ファイルを末尾まで読取り |
| JWS 600 | 27ファイルを末尾まで読取り |
| 全341ファイル、係数100の正本変換 | 339通過、2阻止 |
| 阻止された入力 | 自動車平面-01、-11。曲線塗りの内側パラメータと塗り境界がCAD検査条件を満たさない |

機械報告は `build/format-research/jws-probe-v3.ndjson`。成功数だけで互換性を断定せず、blockedの全診断も残す。線・円弧・楕円・文字・polygon/curve solidと、複数CDataListの読取りを含む。配布サンプルには点、参照block配置、寸法の全種類がそろっていない。合成テストでblock配置の倍率・再帰阻止と共有クラス表、既存JWW変換テストで各プリミティブを補うが、受け側アプリでの表示保証とは区別する。

## 座標と環境

座標の自動推定は行わず、モデルmmへの換算係数を明示指定する。全図形の座標・長さ、文字の大きさ、block基準位置を一様に換算し、block自体の無次元倍率は維持する。元の原点とグループ縮尺はJSONに残す。混在縮尺の解釈は未対応。A3と換算係数に対応するレイアウトを作り、10紙上mmの余白を置く。用紙・原点・収まりは出図前に確認する。

JWSには完全な図面環境がないため、標準色、番号付きレイヤー、印刷幅、Hiragino Sansを補完し、参照blockは展開する。全警告を報告し、形状が脱落する場合は公開しない。JSON報告は正本外の未使用パスへ先に保存し、CAD検査を通った候補だけをディレクトリ単位で公開する。既存プロジェクト・報告の上書きは拒否する。

元JWSは正本に同梱されず、JWW provenanceは生成しない。`exact_round_trip=false`。現行Unicode JWSとJw_cad上の表示・配置・再出力は未確認。

## 部品への変換と貼付

`copy-jws` は全互換性報告を新規外部ファイルへ先に保存し、正本検査を通る図形だけを `cad-clipboard/1` にする。64 MiBを越える入力・出力、空図形、危険な保存先・上書きは拒否する。DesktopのLoad checked JWS partは明示した係数で同じ処理を行い、全JSONと警告を表示する。blockedの場合は元のクリップボードを保持する。報告はプロジェクトや図面の切替後も表示される。

基点はJWS原点を同じ係数で一度だけ換算する。貼付先で新IDと定義対応をレビューし、CAD検査・正本CASを通った候補を一括Undoへ入れる。元JWSとJWW来歴は移さない。合成JWSの原点[2,3]・係数100・線端点[12,23]を用い、Desktopで基点指定→倍率2→90度回転→保存→CAD検査→Undoを検証した。元JWSは不変。Jw_cad側の表示・再出力検証は追加していない。

公式341件の部品変換も339件が通過し、同じ2件を検査で阻止した。元JWSのhashは全件不変。`build/format-research/jws-parts-v1/manifest.ndjson` に全結果とJSON報告のパスを保持する。パレットは `.cadpart.json` / `.jws` の非再帰一覧、JWS係数指定、検査済みサムネイル、選択時hash検査を提供する。Jw_cad上の配置比較は未確認。
